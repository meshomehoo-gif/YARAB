# MIU MIU

تطبيق أندرويد لميادة: تذكير بالدوا وعلاج القطة، روتين يومي، مواهب بتفكّرها بنفسها، إنجازات، ومنبه مواعيد الصلاة.

## طريقة عمل الـ APK

### الطريقة 1: Android Studio (الأسهل)
1. نزّلي Android Studio (مجاني) وافتحي الفولدر `MiuMiu` بعد فك الضغط.
2. استني الـ Sync يخلص (أول مرة بيحمّل مكتبات، فلازم النت شغال).
3. من القايمة فوق: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
4. دوسي **locate** في الإشعار اللي هيظهر، هتلاقي `app-debug.apk`.
5. ابعتيه للموبايل وثبّتيه (فعّلي "التثبيت من مصادر غير معروفة" لو طلب).

لو الموبايل متوصّل بكابل، دوسي **Run ▶** وهيتثبّت على طول.

### الطريقة 2: GitHub (من غير ما تنزّلي حاجة)
1. اعملي ريبو جديد على GitHub وارفعي كل ملفات المشروع في الجذر (فولدر `.github` لازم يكون ضمنها).
2. افتحي تاب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد دقايق نزّلي الملف من **Artifacts** باسم `MIU-MIU-apk`.

## أول تشغيل على الموبايل
- اسمحي بالإشعارات.
- لو الموبايل أندرويد 14، اسمحي بـ "الإشعارات بملء الشاشة" عشان شاشة المنبه تفتح والموبايل مقفول.
- على شاومي وأوبو وسامسونج: اقفلي "توفير البطارية" للتطبيق، وإلا النظام ممكن يأخّر المنبهات.
- من **المزيد ← مواعيد الصلاة** دوسي **📍 حدّدي موقعي** ثم **🔄 تحديث**.

## مواعيد الصلاة
- المصدر: Aladhan API (`api.aladhan.com`)، طريقة رقم 5: الهيئة المصرية العامة للمساحة.
- الموقع الافتراضي القاهرة، ولو سمحتي بالموقع بيستخدم آخر موقع معروف للموبايل.
- بتتنزّل مواعيد 3 أيام قدّام وبتتحدّث تلقائياً مع كل صلاة، وبتشتغل حتى لو النت قطع كام يوم.
- لصوت الأذان: اعملي فولدر `app/src/main/res/raw` وحطي فيه ملف باسم `adhan.mp3` (حروف صغيرة). التطبيق هيستخدمه تلقائياً. استخدمي ملف مسموح لك بيه.

## اللوجو
اللوجو الحالي رسم أصلي مؤقت (وش قطة بوردة). لتغييره: في Android Studio كليك يمين على فولدر `res` ← **New ← Image Asset**، واختاري صورة اللوجو بتاعك، وهيبدّل الأيقونة كلها.
يفضل يكون اللوجو بتاعك أنت أو ليك حق استخدامه.

## الملفات
- `Content.kt`: كل النصوص والدلع والرسايل (عدّلي فيها براحتك).
- `Alarms.kt`: المنبهات والإشعارات وتذكير المواهب.
- `Prayer.kt`: مواعيد الصلاة والتحديث الأونلاين.
- `Screens.kt` و`MainActivity.kt`: الشاشات.
